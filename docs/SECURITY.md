# Security policy

SAND OS is experimental research software and is not suitable for production or safety-critical use.

Do not run untrusted workloads on it. Do not store sensitive data on its images. The project currently has no production-grade security boundary, verified boot chain, sandbox, cryptographic update system, or security audit.

Report suspected vulnerabilities privately to the repository owner rather than publishing exploit details before a fix is available. Include the affected commit, reproduction steps, expected impact, and environment.
